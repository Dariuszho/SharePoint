# Project Structure

```
SharePointPdfSolution/
└── ServerSide/
    ├── PdfGenerator.ashx.cs          # Main C# handler - PDF generation logic
    ├── manifest.xml                  # WSP solution manifest
    ├── CreateWSP.ps1                 # Build script - compiles and packages WSP
    ├── DownloadDependencies.ps1      # Downloads iTextSharp and BouncyCastle DLLs
    ├── QUICK_START.md                # Quick reference guide
    ├── itextsharp.dll                # iTextSharp library (included)
    ├── BouncyCastle.Crypto.dll       # BouncyCastle library (included)
    ├── Examples/
    │   ├── example-simple.aspx           # Basic form with fields
    │   ├── example-html-content.aspx     # Document with sections and tables
    │   └── example-with-attachments.aspx # Form with image attachments
    ├── LAYOUTS/
    │   └── SharePointPdfSolution/
    │       └── PdfGenerator.ashx     # Handler entry point (deployed to _layouts)
    └── PdfHandlerFeature/
        └── Feature.xml               # SharePoint feature definition
```

## Key Files

| File                   | Purpose                                        |
| ---------------------- | ---------------------------------------------- |
| `PdfGenerator.ashx.cs` | Core PDF generation logic with RTL support     |
| `CreateWSP.ps1`        | Build automation - compiles C# and creates WSP |
| `manifest.xml`         | Defines WSP contents and deployment targets    |
| `Feature.xml`          | SharePoint feature registration                |
| `Examples/*.aspx`      | Client-side form templates                     |

## Deployment Artifacts
- `SharePointPdfHandler.dll` - Compiled handler (generated by build)
- `SharePointPdfSolution.wsp` - Deployable SharePoint solution package (generated by build)

## SharePoint Deployment Locations
- Handler: `/_layouts/15/SharePointPdfSolution/PdfGenerator.ashx`
- Assemblies: WebApplication bin folder (not GAC)
